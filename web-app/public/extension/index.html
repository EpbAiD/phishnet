Install the PhishNet Browser Extension

Real-time phishing detection on every page you visit.

Download extension (.zip)

Manifest v3. Works in Chrome, Edge, Brave, and any Chromium-based browser.

Install in Chrome / Edge / Brave

  1. Download the zip using the button above.
  2. Unzip the folder somewhere you won't move or delete (e.g. ~/phishnet-extension/). If you delete the folder, the extension breaks.
  3. Open chrome://extensions/ in a new tab (or edge://extensions/, brave://extensions/).
  4. Turn on Developer mode (toggle in the top-right corner).
  5. Click Load unpacked (top-left), and select the unzipped folder.
  6. The extension appears in your extension list and the toolbar. Click the puzzle-piece icon and pin it for quick access.

Using It

Click the PhishNet icon on any tab. It sends the current URL to the API, gets a phishing verdict, and shows an explanation.

First click after inactivity may take ~30 seconds — the API runs on Render's free tier and cold-starts when idle.

Not on Chromium?

Firefox uses a different extension format (WebExtensions with a slightly different manifest). This build doesn't ship as a Firefox add-on yet. Safari and Firefox support would require repackaging — not currently on the roadmap.
